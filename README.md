# MediReport — ল্যাব রিপোর্ট ম্যানেজার (Android, Kotlin)

Kotlin + Jetpack Compose (Material 3) + Room। অ্যাপে শুধু **অ্যাডমিন**; রোগীরা অ্যাপের ভেতরের **ওয়েব পোর্টালে** ব্রাউজার দিয়ে লগইন করে রিপোর্ট ডাউনলোড করেন।

## ফিচার
- **অ্যাডমিন লগইন:** PBKDF2 হ্যাশ, ৫ বার ভুলে ৩০ সেকেন্ড লক, ইমেইল কোডে পাসওয়ার্ড রিকভারি।
- **ডিফল্ট পাসওয়ার্ড বদল (`admin` / `admin123`):** আগে একটি মেইল সার্ভার + রিকভারি ইমেইল সেট ও টেস্ট মেইল সফল হতে হবে।
- **রোগী ওয়েব পোর্টাল:** কাস্টম পোর্টে (ডিফল্ট 8080) ফোরগ্রাউন্ড সার্ভিস; রোগীর আইডি + ফোন নম্বর (পাসওয়ার্ড) দিয়ে লগইন; শুধু **পাবলিশ করা** নিজের রিপোর্ট দেখা/ডাউনলোড; লগইনে রেট-লিমিট, ৩০ মিনিটের সেশন।
- **পাবলিশ / আনপাবলিশ:** প্রতিটি রিপোর্টে সুইচ, সবগুলো একসাথে, আপলোড বা তৈরির সময়ও। ডিফল্ট: আনপাবলিশড।
- **ইমেইল:** SMTP (Gmail/Outlook/Yahoo প্রিসেট), পাসওয়ার্ড Android Keystore-এ এনক্রিপ্টেড; রিপোর্ট সংযুক্ত করে ইমেইল; ইমেইল টেমপ্লেট (`{patient} {clinic} {report} {id}`)।
- **ল্যাব রিপোর্ট PDF (A4):** হেডার/ফুটার ছবি, ব্যাকগ্রাউন্ড, ওয়াটারমার্ক, Code128 বারকোড, রোগীর তথ্য বক্স, Test | Result | Reference টেবিল (H/L সহায়ক চিহ্ন), তিনটি সিগনেচার ব্লক, একাধিক পাতা।
- **পেজ সেটআপ:** উপর/নিচ/পাশের মার্জিন, ফন্ট সাইজ, লেটারহেড অন/অফ, লাইভ প্রিভিউ, নমুনা প্রিন্ট।
- **প্রিন্ট:** Android Print Framework (PDF ও ছবি)।
- **টেমপ্লেট:** সহজ লাইন-ভিত্তিক ভাষা (`# সেকশন`, `টেস্ট | একক | রেফারেন্স | ডিফল্ট`, `@ লেখার বাক্স`, `> নোট`); ৮টি রেডিমেড (CBC, Urine R/E, RFT, Lipid, TSH, Dengue NS1, X-Ray, General)।
- **এসএমএসে রিপোর্ট জানা:** রোগী নিবন্ধিত নম্বর থেকে `আইডি রিপোর্ট` (যেমন `P-001 CBC`) পাঠালে, অন্য নম্বর থেকে `ফোন আইডি রিপোর্ট` (যেমন `01712345678 P-001 CBC`) পাঠালে অ্যাপ স্বয়ংক্রিয় উত্তর দেয় — শুধু **পাবলিশ করা** রিপোর্ট নিয়ে। অনুরোধ স্থায়ী কিউতে জমা হয়, একটি ওয়ার্কার পুরোনো থেকে নতুন ক্রমে ~২.৫ সেকেন্ড বিরতিতে উত্তর দেয়; একই নম্বরের হুবহু পুনরাবৃত্তি, ১০ মিনিটে ৬টির বেশি, ১ ঘণ্টার পুরোনো এবং ৩০০-র বেশি জমা অনুরোধ বাদ যায়। সেটিংস → এসএমএসে রিপোর্ট জানা থেকে চালু করুন (RECEIVE_SMS/SEND_SMS পারমিশন লাগে)।
- ব্যাকআপ/রিস্টোর (zip), লাইট/ডার্ক থিম, বাংলা/ইংরেজি।

## ওয়েব পোর্টাল ব্যবহার
সেটিংস → রোগীর ওয়েব পোর্টাল → পোর্ট দিয়ে চালু করুন। একই Wi-Fi/হটস্পটের ডিভাইসে `http://<ফোনের-IP>:<পোর্ট>` খুলুন। ইন্টারনেট থেকে ঢুকতে রাউটারে পোর্ট ফরোয়ার্ডিং বা টানেল সার্ভিস লাগবে। পোর্টাল HTTP (HTTPS নয়) — ইন্টারনেটে খোলার আগে রিভার্স প্রক্সি/টানেলে TLS রাখুন।

## GitHub-এ অটো বিল্ড
`.github/workflows/android.yml` প্রতিটি push / PR-এ চলে:
- **debug** APK → Actions → Artifacts
- **signed release** APK (`apksigner verify` সহ) → Artifacts
- `v1.2.3` ট্যাগ push করলে GitHub Release-এ APK যুক্ত হয়

### স্থায়ী সাইনিং কী (গুরুত্বপূর্ণ)
কী না দিলে প্রতিবার অস্থায়ী কী ব্যবহৃত হয় (আপডেট ইনস্টল হবে না)। একবার বানান:
```bash
keytool -genkeypair -v -keystore release.jks -alias medireport -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks   # macOS: base64 -i release.jks
```
Repo → Settings → Secrets and variables → Actions-এ যোগ করুন: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`। `.jks` ফাইল কখনো commit করবেন না।
